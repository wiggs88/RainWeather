# HOWDRY?!

[Open HOWDRY?!](https://wiggs88.github.io/RainWeather/)

A minimal rain radar and short-term precipitation timeline.

## Run locally

```bash
npm install
npm run dev
```

## Verify

```bash
npm run typecheck
npm test
npm run build
```

Pull requests run the same checks in CI; pushes to `main` deploy to GitHub Pages.
